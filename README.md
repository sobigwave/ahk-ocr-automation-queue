# AHK OCR 自动化队列（OCR 队列助手）

一个带 GUI 的 AutoHotkey v2 小工具。按队列依次执行 **OCR 检测、鼠标点击/移动、延时**，适合需要“看屏幕文字 → 点击 → 再判断”的重复操作。

主要功能：

- 执行队列：OCR 检测、左/右键点击、仅移动鼠标、延时，按顺序执行
- OCR 区域框选：鼠标拖一个矩形即可
- 最多 **4 个关键词**，支持简单“任一/全部”模式、**满足指定项数**模式，也支持 **自定义括号组合表达式**
  - 例如 4 个文字中“至少满足 3 项”或“恰好满足 2 项”
  - 表达式例如 `(1或2)且(3且4)`、`(1且2)或(3且4)`、`1且(2或3)`
- OCR 条件满足或不满足时，都可以选择 **继续下一步 / 停止队列**
- OCR 条件满足后可直接执行鼠标动作：**无动作 / 左键点击 / 右键点击 / 仅移动**
  - 可单独设置目标坐标、点击次数、点击间隔或移动速度
- **键盘操作步骤**：发送按键语法或原样文本，可设置重复次数和间隔
- **OCR 详细识别设置**：
  - 语言：自动 / 仅中文简体 / 仅英文 / 中文+英文
  - 图像放大：1x / 2x / 3x（适合小字）
  - 图像处理：原图 / 灰度 / 增强对比度
- 可设置 OCR 最长等待时间、检测间隔；不满足会按间隔重试到超时
- 点击坐标拾取：鼠标点一下即可，支持左键/右键、点击次数、点击间隔
- 鼠标“仅移动”动作，可设置移动速度，不产生点击
- 全局开始/停止快捷键，默认 **F9 开始 / F10 停止**，可修改
- 循环次数：0 表示无限循环
- 每步执行后的延迟
- OCR 测试：先看识别结果、各文字是否命中和表达式结果
- 运行时自动最小化窗口，避免主窗口挡住 OCR 区域
- 彩色分级日志，自动滚动、可清空/复制，保留最近约 400 行
- 配置自动保存到 `config.ini`

## 环境要求

1. **Windows 10 / 11**
2. **AutoHotkey v2.0 或更高版本**（本机已安装）
3. **Windows 中文 OCR 语言**
   - 一般中文系统自带；如果 OCR 启动失败，到：
   - `设置 → 时间和语言 → 语言和区域 → 中文(简体) → 语言选项`
   - 确认已安装“光学字符识别”相关语言功能。

本工具使用 Windows 自带的 `Windows.Media.Ocr`，不需要安装 Tesseract。

## 快速开始

1. 双击 **`启动.bat`**（或直接双击 `OCR队列助手.ahk`，前提是 `.ahk` 已关联到 AutoHotkey v2）。
2. 点击 **`＋ OCR 检测`**：
   - 点 **`框选 OCR 区域`**，在屏幕上拖出要识别的范围；
   - 在“文字1-4”里填写要查找的文字（可只填一个）；
   - 选择条件模式：`任一命中（或）`、`全部命中（且）`、`满足指定项数`或`自定义表达式`；
   - 需要“4 项中满足 3 项”时，选“满足指定项数”，再选“至少/恰好”和项数；
   - 需要复杂组合时，选“自定义表达式”，输入如 `(1或2)且(3且4)`；
   - 需要等待文字出现时，设置“最长等待”和“检测间隔”；
   - 分别设置“满足后”和“不满足后”是继续还是停止；
   - 如需识别成功后自动点击，在“满足后鼠标”选择左键/右键/仅移动，再点“设置…”选择目标坐标；
   - 点 **`识别设置…`** 选择语言（中文/英文/中英混合）、放大倍数和图像处理；
   - 点 **`测试 OCR`** 先验证识别和命中情况；
   - 点 **`添加步骤`**。
3. 点击 **`＋ 鼠标`**：
   - 点 **`拾取坐标`**，鼠标移到目标位置单击（松开确认）；
   - “动作”选择左键点击、右键点击或“仅移动”；
   - 点击时设置点击次数和间隔；仅移动时设置移动速度；
   - 点 **`添加步骤`**。
4. 点击 **`＋ 键盘`**：
   - 输入按键语法（如 `{Enter}`、`^c`）或原样文本；
   - 设置重复次数、间隔和执行后延迟；
   - 点 **`添加步骤`**。
5. 需要停顿就添加 **`＋ 延时`**，填写毫秒数。
6. 设置“循环次数”（0 = 无限循环）。
7. 按 **F9** 开始，按 **F10** 停止（快捷键可修改后点“应用”）。

默认勾选“运行时最小化窗口”。如果不需要最小化，可以取消；但请确保主窗口没有挡住 OCR 区域，否则会识别到主窗口的文字。

## OCR 步骤说明

- **区域**：屏幕物理像素坐标 `X, Y, 宽, 高`。推荐始终用“框选 OCR 区域”获取。
- **文字1-4**：留空的不参与判断；表达式可以引用任意一个已填写的文字。
- **条件模式**：
  - `任一命中（或）`：所有已填文字中任意一个出现即满足；
  - `全部命中（且）`：所有已填文字都出现才满足；
  - `满足指定项数`：统计已填写文字中命中的数量，可选择“至少 N 项”或“恰好 N 项”（N=1-4）。
    - 例如 4 个文字都填写，选“至少 3 项”：命中任意 3 个或 4 个都算满足；
    - 选“恰好 3 项”：必须正好命中 3 个，命中 4 个反而不算满足；
    - 已填项数必须不少于 N，否则保存时会提示。
  - `自定义表达式`：用 `1-4` 代表文字1-4，配合 `且/或`（或 `AND/OR`、`&/|`）和括号自由组合。
- **表达式示例**：
  - `(1或2)且(3且4)`：文字1或2任一命中，并且文字3、文字4都命中；
  - `1且(2或3)`：文字1必须命中，文字2或文字3至少一个命中；
  - `(1且2)或(3且4)`：两组条件任意一组完整命中；
  - 支持全角/半角括号，`且/或` 优先级低于括号、`且` 优先于 `或`。
  - 表达式里引用到的文字必须填写，否则保存/测试时会提示。
- **最长等待**：
  - `0`：只检测一次，马上执行“满足/不满足”的动作；
  - 大于 0：不满足时按“检测间隔”重复识别，直到满足或超时，再执行“不满足后”的动作。
- **满足后 / 不满足后**：
  - `继续下一步`：继续执行队列中的下一步；
  - `停止队列`：立即结束整个队列并记录原因。
- **满足后鼠标**（仅 OCR 条件满足时执行，OCR 类型不会再显示下面独立的“鼠标操作”栏）：
  - `无动作`：只判断 OCR，不操作鼠标；
  - `左键点击` / `右键点击`：在指定坐标点击，可设置点击次数和间隔；
  - `仅移动`：只把鼠标移动到指定坐标，可设置移动速度；
  - 点“设置…”可以拾取目标坐标并修改点击/移动参数；
  - 该动作在 OCR 命中后、执行“满足后/不满足后”动作之前发生；
  - “测试 OCR”只验证识别结果，不会真正执行鼠标动作。
- **忽略内容**：匹配时自动忽略空格、换行、全角空格，并且不区分大小写。
  - 例如 OCR 返回 `开 始 挑 战`，关键词 `开始挑战` 仍可命中。
- **测试 OCR**：会临时隐藏主窗口和编辑窗口，截取当前屏幕区域，显示识别文本、各文字是否命中、表达式结果。测试时请让目标窗口保持可见。

## OCR 详细识别设置

在 OCR 编辑窗口点 **`识别设置…`**：

- **识别语言**
  - `自动（默认中文）`：使用默认中文 OCR 引擎
  - `仅中文简体`：中文 OCR 引擎
  - `仅英文`：英文 OCR 引擎
  - `中文+英文`：使用中文引擎，同时识别中文和英文
- **图像放大**
  - `1x / 2x / 3x`：小字、像素字体建议用 2x 或 3x
- **图像处理**
  - `原图`
  - `灰度`
  - `增强对比度`

这些设置只对当前 OCR 步骤生效，“测试 OCR”和实际运行时使用同一套设置。

> 建议先框选紧一些、加一点内边距，再用“测试 OCR”确认。

## 键盘操作

点主界面的 **`＋ 键盘`** 添加键盘步骤：

- **按键/文本**：例如 `{Enter}`、`{Tab}`、`^c`、`!{F4}`、`abc`
- **发送方式**
  - `按键语法`：支持 AutoHotkey 的 `{Enter}`、`^`、`!`、`+` 等写法
  - `原样文本`：逐字输入，不解释 `{ } ^ !` 等符号
- **重复次数**
- **间隔(ms)**
- **执行后延迟**

键盘会发送到当前前台窗口。运行时勾选“最小化”后，原目标窗口通常会保持前台；如果目标没有焦点，请先切到目标窗口再按 F9。

## 点击与延时

- **拾取坐标**：点“拾取坐标”，鼠标移动后单击，松开鼠标确认；右键或 Esc 取消。
- **动作**：左键点击 / 右键点击 / 仅移动。
- **点击次数**：连续点击次数。
- **每次间隔**：多次点击之间的间隔，单位毫秒。
- **仅移动**：只移动鼠标到指定坐标，不点击；移动速度 `0` 为瞬间，`1-100` 为相对速度（数字越大越慢）。
- **延时步骤**：只在本步类型为“延时”时生效。
- **本步执行后延迟**：所有类型都可用，作为下一步开始前的固定等待。

点击使用当前鼠标的屏幕坐标。若目标程序以管理员身份运行，而本工具没有，Windows 可能会拦截点击，此时请右键以管理员身份运行本工具。

## 快捷键

- 默认：`F9` 开始，`F10` 停止。
- 修改“开始快捷键 / 停止快捷键”后点 **`应用`**。支持 AutoHotkey 写法，例如：
  - `F9`
  - `^F9`（Ctrl+F9）
  - `!s`（Alt+S）
  - `#c`（Win+C）
- 快捷键是全局的，切到游戏/目标窗口后仍然有效。
- 如果快捷键与游戏冲突，改一个不冲突的组合。

## 配置与日志

- 队列、循环次数、快捷键、自动最小化选项会自动保存到 `config.ini`。
- 旧版只有 3 个文字和“或/且”的配置会自动兼容；打开旧步骤后保存即可写入新格式。
- **保存配置** / **载入配置** 可以手动保存或切换配置文件。
- 删除 `config.ini` 后重新启动，就是空队列。
- 运行日志使用彩色分级：
  - 蓝色 `▶`：步骤开始
  - 绿色 `✓`：命中 / 执行成功
  - 橙色 `!`：等待、未满足或提示
  - 红色 `✗`：错误或按条件停止
  - 灰色 `─`：轮次、等待等辅助信息
- 日志保留最近约 400 行，自动滚动到最新；“复制日志”可粘贴到记事本。
- 主窗口右侧日志区已加宽，长文本会自动换行。

## 注意事项与排错

1. **独占全屏游戏可能截不到画面**
   - 请使用“无边框窗口化 / 窗口化”模式。
2. **OCR 识别不准**
   - 尽量把区域框得紧一些，只包含文字；
   - 避免半透明、强背景干扰、艺术字体；
   - 先用“测试 OCR”看实际识别结果，再调整关键词（可只写其中一小段稳定文字）。
3. **OCR 状态显示“不可用”**
   - 检查 `ocr-server.ps1` 是否和主程序在同一目录；
   - 确认系统已安装中文 OCR 语言；
   - 可以手动运行一次：
     ```powershell
     powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\ocr-server.ps1 -Dir .\debug-ocr -ParentPid $PID
     ```
     看错误信息。
4. **点击没有反应**
   - 用“拾取坐标”重新确认坐标；
   - 确认目标窗口在前台；
   - 如果目标是管理员程序，本工具也以管理员身份运行。
5. **窗口被 OCR 识别进去**
   - 保持“运行时最小化窗口”勾选；
   - 或运行前把主窗口移到不覆盖识别区域的位置。
6. **快捷键无效**
   - 确认没有被其他软件占用；
   - 重新填写后点“应用”；
   - 避免开始和停止使用同一个键。

## 示例队列

```text
1. OCR 检测：区域框住“开始挑战/胜利”区域
   文字1=开始挑战  文字2=确认  文字3=胜利  文字4=奖励
   自定义表达式：(1或2)且(3或4)
   满足后=继续下一步，不满足后=停止队列，最长等待=5000ms
   满足后鼠标=左键点击，目标坐标=开始按钮
2. 鼠标操作：拾取“开始”按钮坐标 → 左键点击
3. OCR 检测：文字1=已进入战斗 → 满足后继续，不满足后停止
4. 鼠标操作：拾取某处坐标 → 动作=仅移动，速度=0
5. 延时：1000ms
6. 循环次数=1，F9 开始
```

如果只想判断“文字1-4 中至少满足 3 项”：

```text
条件模式=满足指定项数
方式=至少
项数=3
文字1-4 都填写
满足后=继续下一步
```

## 技术说明

- 主程序：AutoHotkey v2，纯 GUI + 队列调度。
- OCR：常驻 Windows PowerShell 5.1 进程，通过 WinRT `Windows.Media.Ocr` 识别；主程序用临时请求文件通信，避免每次 OCR 都重启进程。
- 截屏：PowerShell 以 Per-Monitor DPI Aware 运行，按屏幕物理像素截取。
- 不修改系统设置，不写注册表，不联网。
